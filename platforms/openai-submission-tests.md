# OpenAI Plugin Directory test prompts

These prompts accompany the `personwise-create-course` Skill and
`https://mcp.personwise.ai/mcp` in the OpenAI Plugin Directory submission.

## Positive activation tests

1. Create a five-page onboarding course for new customer-success hires about handling escalations.
2. Turn this PDF into a source-grounded PersonWise course and publish a link I can share.
3. Resume my unfinished PersonWise course, review the narration and visuals, and finish it.
4. Improve the weak slide text in my draft course without changing its slide order.
5. Create a short museum guide course from these notes and reference images.

## Negative activation tests

1. Write a Python function that sorts a list of integers.
2. Summarize the latest messages in my inbox.
3. Edit an existing video file and export it as MP4.
