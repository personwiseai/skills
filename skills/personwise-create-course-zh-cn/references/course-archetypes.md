# 课程教学结构选择

## 选择原则

先判断学习者完成课程后要理解、判断还是执行，再选择主结构。结构服务于教学结果，不是固定模板。
一门短课通常只有一个主结构，可以借用另一结构的一两个页面，但不要混合到失去主线。

## 概念与心智模型

适合解释新概念、系统或抽象关系。

```text
为什么需要这个概念
核心定义与边界
组成部分及关系
一个具体应用
常见误解与总结
```

视觉优先使用关系图、分层图、因果链和对照，不要连续使用泛化主题图片。

## 操作与流程

适合教会学习者完成一项工作。

```text
目标与完成标准
开始前准备
按顺序执行关键步骤
每个关键节点如何判断正确
错误恢复与练习
```

页面文字给出可扫描的动作和判断点，讲稿解释原因、风险与例外。流程图必须与真实步骤一致。

## 决策与诊断

适合选择方案、排查问题或评估风险。

```text
识别信号
收集必要证据
按优先级排除原因
选择动作
验证结果并升级
```

不得把概率性线索写成确定结论。视觉可用决策树、症状—原因矩阵和优先级表。

## 比较与选型

适合在明确条件下比较多个选项。

```text
共同目标与约束
统一比较维度
各方案优势和代价
典型场景映射
选择规则与下一步
```

只比较资料支持的属性。表格中的空白表示未知，不能用猜测补齐。

## 案例与复盘

适合从真实事件或样例中提炼方法。

```text
背景与目标
关键事实时间线
采取的动作
结果与因果边界
可迁移经验
```

明确区分事实、解释和建议，不从单个案例推导普遍保证。

## 规则、政策与合规

适合解释制度、标准和必须遵守的流程。

```text
适用范围
核心义务或禁止项
责任人与触发条件
例外与升级路径
检查清单
```

保留原始术语、日期和适用边界。资料不完整或可能过期时明确阻塞，不生成看似权威的替代规则。

## 评估结构是否合适

在大纲检查点确认：每页都推动主结构、顺序不可随意互换、没有为了页数重复内容、结尾能验证学习结果。
若多页可以任意调换，通常说明教学弧线还不够清晰，应先修大纲再生成讲稿和图片。
